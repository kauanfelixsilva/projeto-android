# 🤖 Curiosidades de Tecnologia — História do Mascote do Android

Projeto desenvolvido para praticar conceitos de **HTML5 e CSS3**, criando uma página informativa sobre a história do mascote do sistema Android.

O projeto apresenta a evolução do mascote, desde os primeiros conceitos conhecidos como **Dandroids** até o atual **Bugdroid**, utilizando diferentes recursos de HTML e CSS para construir uma página responsiva e organizada.

## 📋 Sobre o projeto

A página apresenta:

- 📱 História do mascote do Android
- 🤖 Informações sobre os Dandroids e o Bugdroid
- 📰 Artigo estruturado com títulos, parágrafos e destaques
- 🖼️ Imagens responsivas utilizando `<picture>`
- 🎬 Vídeo do YouTube incorporado
- 📚 Barra lateral com versões do Android e seus respectivos nomes
- 💡 Elementos `<abbr>` para apresentar informações adicionais
- 🎨 Fonte personalizada utilizando `@font-face`
- 🌈 Cores organizadas através de variáveis CSS
- 📱 Layout adaptado para diferentes tamanhos de tela
- 📌 Rodapé com créditos

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 📚 Conceitos praticados

Durante o desenvolvimento foram praticados conceitos como:

- HTML semântico
- Estruturação de conteúdo
- Elementos multimídia
- Imagens responsivas
- CSS responsivo
- Media Queries
- Variáveis CSS
- `@font-face`
- Incorporação de vídeos
- Organização e estilização de layouts

## 🎯 Objetivo

O objetivo do projeto foi colocar em prática os fundamentos de **desenvolvimento web**, principalmente a estruturação de páginas com HTML5 e a criação de layouts responsivos utilizando CSS3.
